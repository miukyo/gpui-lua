# Interactive Lua DSL Playground

Experiment with the GPUI.lua DSL directly in your browser. This playground runs the Lua engine via WebAssembly, interprets the declarative UI component trees, and executes reactive signal callbacks with zero latency.

<Playground />

## Keyboard Shortcuts

- <kbd>Ctrl</kbd> + <kbd>Enter</kbd> / <kbd>Cmd</kbd> + <kbd>Enter</kbd>: Run and evaluate current Lua code
- Use the **Preset** dropdown above to load various UI layout examples.
- Use **Reset State** to wipe signals back to initial values.
